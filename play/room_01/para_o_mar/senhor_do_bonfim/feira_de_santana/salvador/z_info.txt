=== INFORMATIVO ===

Você encontrou um ponto importante!

Até agora você viu os comandos: 
cd, ls, ls -l, ls -la, cat.

Mas para seguir em frente você
precisará aprender outros comandos,
como o comando de executar script.

Os scripts são arquivos que tem o
suffixo ".sh" em seu nome.

=== COMANDO PARA EXECUTAR SCRIPTS ===

[1] USANDO SOURCE

Digite:
source arquivo.sh

Saiba mais:
https://youtu.be/P7qs23fM2A

O que acontece:
O código script executa no mesmo terminal.

=== DICA ===

Use o comando "source" para executar
os arquivos de scripts dentro do jogo.
