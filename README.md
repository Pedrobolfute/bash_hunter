## 🪶 SOBRE O JOGO

**Bash Hunter** é uma jornada dentro do seu próprio terminal Linux,  
onde você explora diretórios, descobre caminhos ocultos e navega entre mares digitais.  
Cada *room* representa uma nova etapa da sua aventura.

Você começará na **Room 01**, em uma cidade próximo ao porto da **Baía de Todos os Santos, Salvador - BA**. Seu primeiro objetivo é chegar no terminal náutico da Baia de Todos os Santos em Salvador - BA, pegar um barco e zarpar para o mar.

Mas cuidado, marujo — nem todo barco é capaz de atravessar o oceano!

---

## 🪶 INTRUÇÕES

O jogo é composto por **rooms** que são salas virtuais com desafios e objetivos especificos. Para passar para a próxima sala você precisa achar e anotar a chave de cada sala **(key)**, e essas chaves vão lhe permitir abrir portas e baús até o fim dessa jornada. Por isso, encontre todas as cheves e siga em frente, marujo!

## COMANDOS PARA NAVEGAR

Para entrar dentro de uma pasta, use o comando **cd**

> cd nome_da_pasta

[![comando cd](./.engine/.out/1/ascii_comando.png)](https://youtu.be/Soa5VwW09-w)

---

Para sair de dentro de uma pasta (voltar), use o comando **cd ..**

> cd ..

[![comando cd..](./.engine/.out/1/ascii_comando.png)](https://youtu.be/LfHKCZVD1Vk)

---

Para ver os arquivos que está dentro da pasta, use o comando **ls**

> ls

[![comando ls](./.engine/.out/1/ascii_comando.png)](https://youtu.be/PxYCr1UuI9M)

---

Para ver em qual pasta você está, use o comando **pwd**

> pwd

[![comando pwd](./.engine/.out/1/ascii_comando.png)](https://youtu.be/vXOXg9eBC-w)

---

Para ver o conteudo dentro de um arquivo de texto .txt, use o comando **cat**

> cat arquivo_de_texto.txt

[![comando cat](./.engine/.out/1/ascii_comando.png)](https://youtu.be/0KB3nRkfRxw)

---

Para carregar scripts (.sh), use o comando **source**

> source arquivo.sh

[![comando source](./.engine/.out/1/ascii_comando.png)](https://youtu.be/P7qs23fMN2A)
