## 🪶 SOBRE O JOGO

**Bash Hunter** é uma jornada dentro do seu próprio terminal Linux,  
onde você explora diretórios, descobre caminhos ocultos e navega entre mares digitais.  
Cada *room* representa uma nova etapa da sua aventura.

Você começará na **Room 01**, em meio aos portos da **Baía de Todos os Santos, Salvador - BA**.  
Mas cuidado, marujo — nem todo barco é capaz de atravessar o oceano!

---

## ⚙️ COMO BAIXAR E INICIAR O JOGO

1. Baixe o repositório:

  > git clone https://github.com/Pedrobolfute/bash_hunter

2. Abra o terminal

  > CRTL + ALT + T

3. Navegue até a pasta do jogo. 

  - Use o comando **cd** para adentras nas pastas

    > Exemplo: **cd "nome_da_pasta"**
  - Use o comando **ls** para ver em qual pasta você pode entrar
    > Exemplo: **ls**
  - Use o comando **pwd** para saber em qual pasta você está
    > Exemplo: **pwd**
  - Use o comando **cat** para saber o conteúdo de um arquivo.
    > Exemplo: **cat arquivo_de_texto.txt**

4. Dentro da pasta **bash_hunter** use os comandos para chegar até a primeira fase **room_01**

  > cd play

  > cd room_01

5. Carregue a primeira fase do jogo

  > source load_room_01.sh

## 🪶 INTRUÇÕES

O jogo é composto por **rooms** que são salas. Para passar para a próxima  
sala você precisa achar e anotar a chave de cada sala **(key)**, essas  
chaves vão lhe permitir abrir portas e baús até o fim dessa jornada.  
Por isso, encontre todas as cheves e siga em frente, marujo!
