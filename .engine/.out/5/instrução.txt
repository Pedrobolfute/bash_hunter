=== BEM-VINDO AO ROOM_05 ===

Agora o desafio é de lógica!

Você vai usar comandos
para descobrir um código secreto.


=== OBJETIVO ===

O código é a soma de 5 respostas.

Esse código abre o arquivo:

chave.txt


=== DESAFIO ===

Responda:


[1] Quantas vezes "brasil" aparece?
(maiusc. ou minusc.)

Arquivo:
HISTORIA.txt


[2] Quantas vezes "portugal" aparece?
(maiusc. ou minusc.)

Arquivo:
HISTORIA.txt


[3] Quantas vezes "franceses" aparece?
(maiusc. ou minusc.)

Arquivo:
HISTORIA.txt


[4] Quantas linhas têm a palavra "litoral"?


[5] Quantas vírgulas existem no arquivo?


Some tudo.
Esse é o código!


=== COMANDOS QUE VOCÊ VAI USAR ===

grep  → buscar
|     → conectar comandos
wc    → contar


=========== 📘 MANUAL RÁPIDO ===========

[grep]

Busca texto em um arquivo

Ex:
grep "brasil" HISTORIA.txt

-i  → ignora maiúsculas/minúsculas
grep -i "brasil" HISTORIA.txt

-o  → mostra só o que encontrou
grep -o "brasil" HISTORIA.txt

-w  → palavra exata
grep -w "brasil" HISTORIA.txt


[ | ]

Liga comandos

Ex:
comando1 | comando2


[wc]

Conta resultados

-l → conta linhas
-w → conta itens

Ex:
grep -o "," HISTORIA.txt | wc -w
