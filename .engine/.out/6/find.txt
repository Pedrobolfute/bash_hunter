==================================================
📘 MINI TUTORIAL - FIND
==================================================

O comando "find" serve para
procurar arquivos e pastas.


🎥 Vídeo básico:
https://youtu.be/P3omOTLo6mM


--------------------------------------------------
🔎 COMO USAR
--------------------------------------------------

find caminho opção nome

Exemplo:
find /home -name "arquivo.txt"


--------------------------------------------------
🔎 EXEMPLOS
--------------------------------------------------

[1] Buscar arquivo pelo nome:

find /home -name "arquivo.txt"


[2] Ignorar maiúsculas/minúsculas:

find /home -iname "arquivo.txt"


[3] Buscar só pastas:

find / -type d


[4] Buscar só arquivos:

find / -type f


[5] Evitar erros:

find / -name "arquivo.txt" 2>/dev/null


==================================================
📘 FIND + GREP
==================================================

Use "grep" para filtrar resultados.


Exemplo:

find / | grep "config"

→ Mostra só o que tem "config"


Outros exemplos:

find / | grep "\.log$"

find /home | grep "/Documentos/"

find / | grep -i "senha"


--------------------------------------------------
⚠️ IMPORTANTE
--------------------------------------------------

- find → procura
- grep → filtra
- "/" pode ser lento
- use com cuidado


==================================================
📘 DICA
==================================================

Prefira usar o find direto:

✔ Melhor:
find / -name "*.log"

✖ Evite:
find / | grep ".log"

(melhor desempenho)
